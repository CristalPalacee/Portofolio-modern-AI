# Overview AI Chatbot Backend

## Ringkasan

Project ini adalah backend AI chatbot kecil menggunakan NestJS, Prisma ORM v7, MariaDB/MySQL, dan Ollama.

## Tujuan

- Membuat API chatbot lokal.
- Menyimpan riwayat percakapan.
- Menghubungkan NestJS dengan Ollama.
- Menyiapkan struktur backend yang rapi dan mudah dikembangkan.
