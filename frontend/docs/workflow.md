# Workflow Project

## Tujuan

Membangun website portfolio static modern tanpa backend.

## Urutan Pengerjaan

1. Setup Next.js
2. Setup static export
3. Setup Tailwind CSS
4. Setup Framer Motion
5. Buat struktur folder
6. Buat data static
7. Buat layout utama
8. Buat homepage section
9. Buat halaman projects
10. Buat halaman project detail
11. Buat halaman contact
12. Tambahkan animasi
13. Optimasi responsive
14. Optimasi SEO
15. Build static
16. Deploy

## Batasan Project

Project ini tidak memakai:

- Backend
- Database
- API route
- Auth
- Middleware
- Server Action untuk mutation
- Prisma
- NestJS
