# SEO Guideline

## Metadata

Setiap halaman utama harus memiliki metadata.

Halaman yang perlu metadata:

- Homepage
- Projects page
- Project detail page
- Contact page

## Open Graph

Gunakan image khusus:

```txt
public/images/og-image.svg
```

## Struktur Heading

- H1: Judul utama halaman
- H2: Section utama
- H3: Sub section

## Image

Semua gambar project harus memiliki alt text yang jelas.
